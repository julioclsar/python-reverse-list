# Reverse List CLI

Lê dez números e exibe a lista na ordem inversa.

Este é um projeto independente criado durante um curso de Visão Computacional.

## Tecnologias

- Python
- Biblioteca padrão do Python

## Como executar

~~~powershell
Nenhuma dependência externa.
python reverse_numbers.py
~~~

## Arquivos

- **reverse_numbers.py**: implementação do projeto.
- Arquivos de imagem/classificador necessários à demonstração.
